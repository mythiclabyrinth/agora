# Agent image sources

These are display-sized copies of the projects' own images. Keep the upstream
files untouched and resize/crop only the copies used by Agora.

- `pantheo.png` — `assets/pantheo.png` in
  [tomjose92/pantheo](https://github.com/tomjose92/pantheo). The original
  1024×604 artwork is center-cropped and resized to 256×256.
- `hermes.png` — `apps/desktop/assets/icon.png` in
  [NousResearch/hermes-agent](https://github.com/NousResearch/hermes-agent).
  Resized from 1024×1024 to 256×256.
- `openclaw.png` — `apps/linux/src-tauri/icons/icon.png` in
  [openclaw/openclaw](https://github.com/openclaw/openclaw). Resized from
  512×512 to 256×256.

The Codex, Cursor, Claude, and Antigravity images come from their
corresponding connector directories under `bridges/*-cli/assets/`. The
Antigravity mark is Google's own `https://antigravity.google/favicon.svg`,
rendered on a full-bleed white square (its light-theme background) without the
favicon's circular frame.
