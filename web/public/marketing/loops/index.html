Agora as the control room for agent loops, with every run also recorded in Linear. Narrated; recreated from real usage; the numbers are real.

Share copyLoop engineering with Agora: a Loop Monitor opens a thread for every loop and schedules each run, Claude leads, Codex writes the draft PRs, Cursor sweeps the evidence, and when a loop stalls the watchdog flags it so Claude can revive it. Every run is also recorded in Linear, so Linear plus the thread are the source of truth, while the agents run on your machine with the Claude Code, Codex and Cursor subscriptions you already have, steered from iOS, desktop or web. 27 days, 13 loops, 3,526 messages, 459 scheduled runs, 35 merged PRs (scenes recreated from real usage; the numbers are real).

The Agora scenes were recreated in a throwaway local instance with a fictional workspace, and the messages are paraphrased from real loop threads. The Linear scene recreates Linear's issue page with fictional data. Narration was generated locally with Voicebox using a built-in preset voice. Every number comes from 27 days of real loops on a production Agora.
