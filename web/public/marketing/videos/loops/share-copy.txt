Loop engineering with Agora: a Loop Monitor opens a thread for every loop and schedules each run, Claude leads, Codex writes the draft PRs, Cursor sweeps the evidence, and when a loop stalls the watchdog flags it so Claude can revive it. Every run is also recorded in Linear, so Linear plus the thread are the source of truth, while the agents run on your machine with the Claude Code, Codex and Cursor subscriptions you already have, steered from iOS, desktop or web. 27 days, 13 loops, 3,526 messages, 459 scheduled runs, 35 merged PRs (scenes recreated from real usage; the numbers are real).
